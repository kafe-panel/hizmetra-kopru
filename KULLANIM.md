# Hizmetra Köprü — Kullanım Koşulları

1. Bu program MIT lisansıyla açık kaynaklıdır (LICENSE); "olduğu gibi" sunulur, garanti verilmez.
2. Program yalnız Hizmetra Panel'inizden gelen fişleri bilgisayarınızdaki yazıcılara basar.
3. Dışarıdan bağlantı kabul etmez; bağlantıyı daima program başlatır (giden HTTPS).
4. Fiş içeriği kalıcı olarak saklanmaz ve günlük dosyasına yazılmaz.
5. Panelden "Kaldır" dediğinizde bu bilgisayarın erişimi anında kesilir.
6. Sorular: github.com/kafe-panel/hizmetra-kopru/issues
